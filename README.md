# bingoring/homebrew-tap

Homebrew casks for [Tokens Are Running Out](https://github.com/bingoring/tokens-are-running-out), a macOS menu bar app that shows why your Claude Code usage drained.

```bash
brew install --cask bingoring/tap/tokens-are-running-out
```

The cask is updated automatically when a release is published. Every release is signed with Developer ID and notarized by Apple.
